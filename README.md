# README.md

Build a small agent that, given a GitHub repository, reads its open issues, picks one it can
reasonably fix, makes the change, and opens a pull request that references the issue.

Use whatever language and tools you like. You can use the AI assistant for anything, but
narrate what you're doing as you go. We have about an hour. When time's up, push whatever
you have to a branch and we'll talk through it.

Target repo: https://github.com/HorusAlkebulan/imhotep-issue-agent-target
